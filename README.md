# ARAB SOFT — Professional Service Center Management System

برنامج Windows Desktop لإدارة مركز صيانة أجهزة بشكل متكامل.

## أهم الوظائف
- تسجيل دخول ومستخدمون وصلاحيات.
- تغيير كلمة المرور وإدارة المستخدمين.
- العملاء + سجل كامل لأوامر كل عميل.
- استلام الأجهزة برقم أمر تلقائي.
- نوع الجهاز، الموديل، IMEI، Serial، اللون، الملحقات، حالة الجهاز.
- عطل العميل + التشخيص الفني + الفني المسؤول + الأولوية.
- دورة حالات الصيانة: استلام، فحص، انتظار العميل، إصلاح، انتظار قطعة، تم الإصلاح، جاهز، تسليم، ملغي.
- صور الجهاز والمرفقات محفوظة داخل مجلد النظام.
- قطع الغيار مرتبطة بأمر الصيانة وتخصم من المخزون تلقائياً.
- مخزن: توريد، صرف، حد إعادة الطلب، مورد، أسعار شراء وبيع.
- حساب تكلفة الإصلاح: مصنعية + قطع غيار - خصم.
- دفعات متعددة وطرق دفع مختلفة والمتبقي.
- تسليم الجهاز وحساب ضمان الإصلاح تلقائياً.
- إيصالات PDF للاستلام والتسليم + QR.
- Dashboard وإحصائيات تشغيلية ومالية.
- تقارير CSV للصيانة والعملاء والمدفوعات والمخزن والحسابات.
- Backup باستخدام SQLite Online Backup API للحفاظ على سلامة قاعدة البيانات.
- إعدادات المركز والعملة والضمان ونص الإيصال.
- Audit Log.
- حقول مخصصة.

## التشغيل من المصدر على Windows
1. ثبّت Python 3.10 أو أحدث.
2. شغّل `START_WINDOWS.bat` أو نفّذ:
   `python -m pip install -r arabsoft_service_system\requirements.txt`
   ثم `python launcher.py`
3. الحساب الافتراضي: `admin / admin`.

## بناء EXE على Windows
شغّل `BUILD_WINDOWS.bat`.
السكريبت ينشئ بيئة افتراضية، يثبت المتطلبات، ثم يستخدم PyInstaller لإخراج:
`dist\ARAB_SOFT_Service.exe`

> ملاحظة: PyInstaller يبني تطبيق Windows على Windows؛ بيئة العمل الحالية هنا Linux، لذلك تم تجهيز المصدر وملف البناء واختبار الكود وقاعدة البيانات، لكن لا يمكن إخراج Windows EXE أصلي من هذه البيئة.

## مكان البيانات
