# ARAB SOFT - نظام إدارة الصيانة

نسخة مصدرية أولى لنظام Windows Desktop لإدارة استلام وتسليم أجهزة الصيانة.

## التشغيل
- Windows + Python 3.10 أو أحدث.
- شغّل `python run.py`.
- الحساب الافتراضي: `admin` / `admin`.
- قاعدة البيانات تحفظ تلقائياً في `%USERPROFILE%\\ArabSoftService\\service_system.db`.

## الوظائف الحالية
- تسجيل الدخول وصلاحيات المستخدمين.
- العملاء وسجل الأجهزة.
- استلام أوامر الصيانة وترقيم تلقائي.
- IMEI / Serial / الملحقات / حالة الجهاز / العطل / التشخيص.
- حالات دورة الصيانة والفني المسؤول والأولوية.
- دفعات وحساب المتبقي.
- تسليم الجهاز.
- فنيون.
- مخزن وقطع غيار وحركات توريد/صرف.
- مصروفات وإيرادات.
- Dashboard وتقارير يومية.
- تصدير CSV.
- Backup لقاعدة البيانات.
- إعدادات المحل والعملة والضمان.
- سجل Audit للأحداث الرئيسية.

## المرحلة التالية المقترحة
- شاشة طباعة إيصال استلام وتسليم PDF.
- صور الجهاز والمرفقات.
- QR/Barcode.
- شاشة فحص فني تفصيلية.
- ربط قطع الغيار بأمر الصيانة وتحديث المخزون تلقائياً.
- تقارير مالية متقدمة وربحية كل أمر.
- صلاحيات دقيقة لكل زر/شاشة.
- بناء EXE Installer للويندوز.
